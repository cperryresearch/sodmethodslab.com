# SOD Methods Lab LLC Website

This repository contains the public landing page for **SOD Methods Lab LLC**.

The site is intended to function as a restrained public front door for the lab, not as a full technical archive or service marketplace.

## Purpose

The landing page should:

- establish SOD Methods Lab LLC as a real methods and documentation lab;
- describe the lab’s public posture in restrained language;
- acknowledge both the SOD theoretical framework and applied tools such as PC-MAW;
- direct visitors toward public/open development materials when appropriate;
- state clear boundaries around unsupported or non-offered claims;
- provide a professional contact path.

## Public posture

SOD Methods Lab LLC develops structured motion-analysis methods, audit interfaces, and technical documentation for restraint-first review of trajectory and state-segmented motion data.

The lab emphasizes traceability, bounded interpretation, and clear separation between observed motion structure and unsupported conclusions.

## Included in V1

The V1 landing page includes:

- short lab description;
- lab posture section;
- current focus areas;
- public/open work section;
- boundary of claims;
- private/applied review boundary;
- contact email.

## Not included in V1

The V1 landing page should not include:

- service pricing;
- client intake forms;
- regulatory or safety-certification language;
- object identification claims;
- origin claims;
- propulsion claims;
- proprietary thresholds;
- internal review logic;
- cohort-specific packaging;
- decision or emission logic;
- detailed Orb candidacy claims.
